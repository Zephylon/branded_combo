## 사용법
1. 인게임 스크린샷을 찍는다.
2. 스크린샷을 프로그램에 ctrlV한다.
3. 전개 추천 실행을 한다.
4. 뜨는 전개 추천 리스트 중 하나를 선택하고, 리플레이를 확인 후 따라 전개한다.
